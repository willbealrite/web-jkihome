# JKI Home Church Official Website

Official website of JKI Home Church.

## Project Structure

- `frontend/` — React.js, Vite, and Tailwind CSS.
- `backend/` — Node.js, Express.js, and REST API.
- `asset/` — Official church assets.

## Technology Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express.js
- PostgreSQL
- REST API
- JWT Authentication
